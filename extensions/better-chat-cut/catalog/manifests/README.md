# Better Chat Cut catalog manifests

Place production `*.asset.json` files in this directory (recursive subfolders allowed).

This folder is the default Global Asset Registry root. Override with `BETTER_CHAT_CUT_ASSET_CATALOG_ROOT` when needed.

Do not put test fixtures here — use `packages/global-asset-registry/fixtures/`.

See [docs/asset-manifest-v1.md](../../../docs/asset-manifest-v1.md).
