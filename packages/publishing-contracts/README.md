# Publishing Contracts (M6B)

Pure TypeScript contracts for Better Chat Cut publishing:

- PublishingRequestV1, PublishingMetadataV1, PublishingComplianceV1
- ThumbnailPlanV1, ReleasePlanV1, PublishingPackageV1
- Validators, stable hashes, chapter/attribution transforms

No filesystem, MCP, React, or Remotion dependencies (aside from SceneDocument type shapes used by thumbnail plans).

Revision: `PUBLISHING_REVISION` / `getPublishingRevision()`.
